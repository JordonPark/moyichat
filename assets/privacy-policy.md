## 처리하는 정보

모이챗은 회원가입 없이 사용할 수 있어요. 모바일 앱은 대화, 첨부한 사진, 사진에서 읽은 정보, AI 답변, 대화 요약, 프로필 사진과 설정을 앱 전용 저장 공간에 보관해요. 대화와 사진 분석은 기기에서 실행되며 이 내용은 모이챗 운영자나 외부 AI 서비스로 전송되지 않아요. iOS에서는 해당 앱 저장 공간을 기기 백업에서 제외하도록 설정해요.

웹 미리보기에서는 대화와 첨부 사진이 사용 중인 브라우저의 사이트 데이터에 저장돼요. 미리보기에서는 예시 답변을 확인할 수 있어요.

## 인터넷에 연결하는 경우

오프라인 AI를 처음 준비할 때 동의를 받아 Hugging Face에서 약 1.52GB의 모델 파일을 내려받아요. 다운로드 서비스는 파일을 전달하는 데 필요한 IP 주소와 같은 연결 정보를 받을 수 있어요. 앱 내 업데이트를 지원하는 베타 빌드에서는 사용자가 업데이트를 확인할 때 Shorebird에 앱 버전과 플랫폼 등 업데이트에 필요한 정보가 전달될 수 있어요.

광고가 활성화된 빌드에서는 Google AdMob이 비개인화 배너를 제공해요. 광고 제공 시 광고 상호작용, 기기 정보, IP 주소에서 파악한 대략적인 위치 등 SDK의 데이터 처리가 발생할 수 있어요. 광고 요청에 대화와 사진을 포함하지 않아요. 광고 개인정보 설정이 제공되는 지역에서는 앱 정보에서 광고에 대한 선택을 바꿀 수 있어요.

배너 옆 **광고 정보 및 신고**를 누르면 광고 식별 정보와 신고 시각을 이메일에 담을 수 있어요. 사용자가 이메일을 보내면 모이챗 지원팀이 광고 문제를 확인하고 답변하는 데 사용해요.

## 보관과 삭제

대화와 사진은 사용자가 삭제할 때까지 앱에 보관돼요. 작업 메뉴에서 개별 작업과 첨부 사진을 삭제할 수 있고, **앱 정보 → 저장된 데이터 삭제**에서 대화 전체와 첨부 사진, 사용자 지정 프로필을 지울 수 있어요. 사진 앱의 원본은 사진 앱에서 관리해요. 앱을 삭제하면 iOS의 앱 전용 저장 공간이 삭제돼요. 웹 미리보기의 기록은 앱 정보에서 지우거나 브라우저에서 사이트 데이터를 삭제할 수 있어요.
